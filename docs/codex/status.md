# 開発状況

最終更新: 2026-11-01。実装・自動テスト・実機検証の範囲を区別する。

## 実装済み

- Rust + wgpu、CPUのBoidsとGPUインスタンス描画。魚以外のモデルは未実装。
- 葉形の魚、目のないディープブルーの配色、速度依存の尾振り。
- 深海グラデーションと3層のマリンスノー。背景もシーン時計で更新。
- 最大速度150px/シーン秒、孤立個体の復帰加速、群れの弱い巡航補助。
- アイコン矩形の回避、安全な初期出現、矩形侵入時の出口探索。画面端の外向き速度を内側へ補正。
- マウス移動時の逃避、静止10秒後の局所的な接近と半径24pxの衝突判定。
- WindowsのWorkerW / Progman連携、診断ログ、プレビュー、単一起動。
- 全画面を共有するマルチモニター表示。初期状態は全画面ON、個別ON/OFF・保存。隣接画面間に内壁を設けず、無効画面・配置の隙間を回避。
- Windowsからモニター製品名を取得。取得できない場合はGDIデバイス名。
- 日本語のDeep Glass設定画面。変更しても閉じず、×・Escは非表示、「終了」は常駐終了。
- 匹数・FPS・時間倍率のスライダー、独自描画と平滑化。値はドラッグ解放時に保存。
- トグルの180msアニメーションと連続クリックへの対応。
- Zen Kaku Gothic Newのプロセス内メモリ登録、魚のEXE・通知領域・ヘッダーアイコン。
- FPS=0、時間倍率=0、全モニターOFFによる停止。バッテリー・ロック・スリープ・全画面に応じた省電力制御。
- Windows CI、パス検査付きの配布ビルド、Release公開後に実行用ZIPを添付するワークフロー。

## 検証済みの範囲

直近のWindows/GNUの自動テストは29件成功・性能計測1件ignore。Releaseビルド成功。設定互換性、時計、群泳・境界・障害物、モニター領域の計算、コントロール通知、WGSLを検証している。詳細・過去の件数は[validation.md](validation.md)に記録する。

READMEのGIFは現在のシミュレーションとシェーダーによるオフスクリーン描画で作成する。デスクトップ録画や実壁紙の統合確認を意味しない。

## 未検証・制約

- 実際の複数画面での往来、混在DPI、ホットプラグ、複数GPU・HDRの保証。
- 単一Surfaceのため、全画面の外接矩形はGPUの最大テクスチャ寸法以内が必要。
- 全画面判定は代表モニター基準で共有シーン全体を停止する。
- 多数の画面に対する設定一覧のスクロールは未実装。
- Explorer再起動後の自動再接続、GPU全体の再作成は未実装。
- 省電力の全状態切替・消費電力は実測が必要。
- MSVC・GitHub Releaseイベントの実行結果はローカルGNUの成功と区別する。
- macOS連携・ビルド、魚以外のモデル、GPU compute、自動起動、インストーラー、署名は未実装。
- 密集時は近傍探索が最悪O(N²)。アイコン取得は時間上限までの部分的な結果となり得る。

## Plant追加開発（2026-11-01）

feat/plant-sceneで実装中。雨による発芽・水分補充、草花と木の長期成長、自然な種の拡散、枯れない世代更新、庭の保存を追加。成長時計は描画停止と独立し、全画面で隠れていても進む。0倍率・終了中・Fish選択中は進めない。十分な水分で草花1時間・木24時間、乾燥時は5%の速度。仕様・初期値・制約は[plant-scene.md](plant-scene.md)を参照。src/plant.rsとplant.wgslはFishのモデル・描画から分離する。mainやv1.0.0へ反映済みとは扱わない。

Plant追加調整（2026-11-03）: 高速デバッグ育成は通常の庭と分離した保存先を使用。雲は各画面で最大1群、待ち時間と移動速度にばらつきを付け、自然雨で給水する。手動給水は左ボタンを押している間のみカーソルに追従し、給水半径30px。木は楕円の樹冠が拡大する方式を維持する。自然雨の追加給水は描画更新中のみ。詳細と制約はplant-scene.mdを参照。
