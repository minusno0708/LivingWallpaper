# 開発状況

## 現在の実装

- Windows 11を主対象とするRust + wgpu製の壁紙アプリ。最初のモデルは魚のBoids群泳。
- 空間ハッシュによる近傍探索、画面境界・アイコン矩形の回避、矩形侵入時の押し出し。
- wgpuのインスタンス描画とWGSLによる魚・尾の表現。
- 従来WorkerWとraised desktop向けProgman内配置、プレビュー、ログ・エラー表示。
- マウス停止時の接近・移動時の逃避とON/OFF。
- トレイから開く日本語のDeep Glass設定ウィンドウ（項目変更で閉じない）、匹数・FPS変更、停止、設定保存、単一起動。
- バッテリー、全画面、ロック、スリープに応じた描画抑制。
- サーフェス再設定、Explorerホスト消失検出、トレイ再作成通知への対応。
- 設定の範囲制限と旧アプリ設定の読込。
- Windows用CIと、配布バイナリのパス置換・検査を含むビルドスクリプト。
- Release公開を起点にWindows x64 MSVCでビルドし、実行用ZIPをAssetsへ添付するワークフロー。実際のReleaseイベントでの動作は未検証。

- 暗い深海グラデーション、ごく淡い拡散光、大小のマリンスノーが沈降・横揺れする3層のGPU描画。背景は魚と同じ描画・停止制御を共有。

- 全シーン共通の時間倍率（0〜2倍、0.25刻み）と継続的なシーン時計。0倍・自動停止後に経過時間をまとめて追いつかせない。

## 未実装・制約

- 魚以外のモデル。モード選択UI・設定保存・モデル生成の入口は実装済みだが、選択肢はFishのみ。モデル・描画契約にも魚を前提とする部分がある。
- macOSの壁紙・アイコン・グローバルマウス・トレイ・電源通知。macOSのビルド・実行も未検証。
- 混在DPI・GPUをまたぐ構成の実機での保証。
- GPU compute、自動起動登録、インストーラー、署名。
- Explorer再起動後の自動再接続、GPUデバイス全体の再作成。
- 密集時の近傍探索は最悪O(N²)。大量アイコンは取得時間上限までの部分的な回避。
- フレーム処理後に待機するため、実FPSは設定上限より下がることがある。

## 検証

自動テストは設定値、設定の引き継ぎ、マウスの力、群泳の安定性・障害物回避、WGSL検査を対象とする。性能測定テストは通常ignoreする。

実機でのトレイ操作、実マウス、アイコン移動、電源・ロック・スリープ、ゲーム、混在DPI、他GPU等は、対象環境で個別に確認する。過去の起動確認をこれらの合格とみなさない。[validation.md](validation.md) に現在の検証範囲を記録する。

## 次の作業の候補

ユーザーの依頼に合わせて選び、一括して未実装機能を追加しない。

1. 新しいPCでビルド・プレビューを確認し、実機の受入項目を検証する。
2. フレーム待機・密集時の探索・アイコン取得の負荷を必要に応じて測定する。
3. 次のモデルを追加する際にモデル識別・設定・中立な描画契約・選択UIを検討する。
4. macOSはOS境界の別バックエンドとして実装する。


## 設定スライダーの描画修正（2026-11-01）

標準コントロールの即時描画と独自描画が混ざる経路を除き、値表示の白背景・つまみの残像を防ぐよう変更。つまみはドラッグ中にピクセル単位で追従し、値は既存の刻みを維持する。数値が変わらないときの文字列再設定を省く。実際のデスクトップ上での操作感は修正後のEXEで確認が必要。検証範囲はvalidation.mdを参照。

## マルチモニター拡張（2026-11-01）

初期状態で全モニターを有効にし、Windowsの物理ピクセル配置に沿った共通シーンとして扱う。負の座標を含む全画面の外接矩形へ壁紙ウィンドウを配置し、表示リージョンは有効画面の和集合に制限。無効画面・配置の隙間はモデルの障害物として渡し、アイコン回避OFFでも有効。隣接する有効画面間に内壁は作らず、魚の状態・背景時刻・匹数を全画面で共有する。非隣接画面へのワープは実装しない。

設定画面下部のモニタートグルは画面番号・解像度を表示し、切替は表示デバイス名で保存する。初期値のdisabled_displaysは空で、旧設定も全画面有効。新規接続画面は既定で有効。全画面OFFも許可し、常駐・設定操作は維持したまま描画・シミュレーションを停止する。画面構成は約2秒ごとに更新し、一覧は設定画面を開くと再取得する。設定画面の高さは一覧数に応じて拡張するため、多数の画面や小さい作業領域ではスクロール対応が今後必要。

Windows/GNU stableで27件成功・性能測定1件ignore。追加テストは隣接画面の内壁なし、負の原点、無効画面・斜め配置の空白、旧設定の全画面既定値・保存、モニタートグルの通知を対象とする。実機での複数画面・画面間移動・混在DPI・ホットプラグ・GPUをまたぐ構成は未検証。単一の大きなwgpu Surfaceを使うため、外接矩形の幅・高さはGPUの最大テクスチャ寸法以下が必要で、巨大な画面構成の分割描画は未実装。省電力の全画面判定は既存の代表モニター基準で共通シーン全体を停止する。macOS連携は未実装。
