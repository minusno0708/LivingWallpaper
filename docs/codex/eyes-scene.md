# Eyesシーン

状態: feat/eyes-sceneで実装中。mainへ未マージ。仕様の出発点はホラー調の目の出現・消失。

## 合意した動作

- 黒背景に複数の目が非同期に現れ、その場に留まって閉じて消える。
- 特殊イベントは自動でランダムに発生させる。
- 一斉開眼・巨大目の前は新規出現を止め、全て閉じたことを確認して短い暗転を挟む。
- カーソル注視は静止中に限り、カーソルの周囲へ目を置いて中心を見つめる。
- 正面静止・カーソル追従・ランダムな視線移動のパターンは全眼で同期する。
- リアル寄りの怖い外観。白目の血管、暗い虹彩、瞳孔、角膜の反射とまぶたの縁を描く。

## 初期実装の調整値

以下の秒数・頻度は調整可能な実装値で、ユーザーが固定した仕様ではない。

- 通常: 0.3〜1.4シーン秒おきに出現、最大14眼、寿命3〜9秒。
- 開眼0.22秒・閉眼0.35秒。移動せずサイズ・出現位置に差をつける。
- 14〜30秒の通常期間の後、一斉開眼または巨大目を抽選。暗転1〜3秒、保持4〜7秒。
- 一斉開眼は12眼。巨大目は有効モニターを一つ選び、その画面いっぱいに1眼。
- カーソルが実時間10秒静止すると通常状態から注視イベントへ移る。半径180px・最大8眼。画面外へはみ出す候補は除外するため、端では円の一部だけになる。
- カーソル移動中・反応OFFでは注視イベントを中止する。同じ静止期間では繰り返し発動しない。
- 全体の視線パターンは2〜6秒ごとに選び直す。ランダム移動中は0.15〜0.8秒ごとに視線目標を更新。注視イベント中はカーソルへ固定する。

## 実装の境界

src/eyes.rsが出現・イベント・視線を管理し、src/eyes.wgslがインスタンス描画する。魚のBoidsへ目のデータを流用せず、FishモデルとEyesSceneを分離する。現時点で全シーン共通の抽象トレイトへ統合はしていない。

RendererはEyesでは魚・マリンスノーのパスを使わず黒背景に描く。現行の共通時計・時間倍率・FPS・モニター表示・省電力制御は共通。目の見た目はテクスチャではなく手続き的シェーダーによる写実風表現。実際のリアルさ・怖さは利用者による外観確認が必要。

EyesではFish専用の匹数とアイコン回避項目を隠す。目はアイコンを避けず、その背面に現れる。カーソル反応・時間倍率などは維持する。シーン切替時にEyesの進行状態を初期化し、選択モードは既存設定へ保存する。

## 確認項目

全眼閉鎖前に特殊イベントが出ないこと、暗転を挟むこと、一斉開眼の時刻一致、静止条件と移動後の注視終了、黒背景・まぶた・虹彩の描画、Fish切替・設定互換・停止復帰、複数画面での出現位置を確認する。
