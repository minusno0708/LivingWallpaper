# 要件

最終整理: 2026-10-31。実装済みであることの証明ではありません。実装状況は [status.md](status.md)、検証結果は [validation.md](validation.md) で別に管理します。

## 目的・方針

自然や生物の群れの振る舞いをPCの壁紙上でシミュレーションする。アプリ名は `Living Wallpaper`、パッケージ名は `living-wallpaper`。魚だけに用途を限定する名称へ戻さない。

主対象はWindows 11。将来macOSも対象にできるよう、共通モデル・描画とOS固有処理を分離する。パフォーマンスと低負荷を技術選定・実装の判断基準にする。

## 機能要件とMVPの判断

| ID | 要件 | MVPの範囲・受入観点 |
|---|---|---|
| F1 | PCの背景として設定できる | Windows 11のプライマリ画面でアイコン背面に表示し、通常のデスクトップ操作を妨げない。終了後は通常の壁紙が見える |
| F2 | 設定画面は基本的にバックグラウンド、ポップアップ形式 | 常駐中はトレイから小さな設定UIを開く。MVPではWindows標準メニューを許容する |
| F3 | 複数の群れモデルを選択できる拡張性 | 最初は魚のBoidsのみ実装。モデル追加の境界を用意し、複数モデルの実装・選択UIは後続作業 |
| F4 | デスクトップアイコンが障害物になる | アイコンとラベルの矩形を読み、魚が回避する。アイコンの移動後も取得周期に応じて追従する |
| F5 | マウスカーソルが群れに影響する | 停止すると接近、動くと逃避。ON/OFF可能。物理ピクセル座標を群泳座標に合わせる |
| F6 | FPS制限・省電力 | FPS上限と手動停止。バッテリー駆動時の上限低下、全画面・ロック・スリープ時の描画抑制 |
| F7 | 設定の保持 | 操作後に保存し再起動時に反映。読み込んだ値を安全な範囲に制限する |

## 技術要件

- Rust + wgpuを共通基盤とする。現在のMVPではwinit、windows-sysを併用。
- CPUシミュレーションとGPUインスタンシングで描画する。GPU computeの利用は必須要件ではない。
- 不必要な常時描画やビジーループを避け、低速フレームでもシミュレーションの更新幅を制御する。
- Windows非公開API・Explorer内部構造への依存を明記し、失敗時の診断とプレビュー経路を残す。
- macOS未対応箇所を明示する。Windowsだけの成功をクロスプラットフォーム対応の証明としない。
- ソース、ビルド手順、検証結果を保存し、別PCで再現できるようにする。

## 現在のMVPで採用したパラメーター

以下は実装上の初期値・選択肢であり、ユーザーが固定した永続的な製品要件ではありません。変更時は動作・負荷・設定互換性を確認します。

- 初期値240匹、30 FPS。メニューの匹数120 / 240 / 500 / 1000、FPS 15 / 30 / 60。
- 設定値の許容範囲は32～1000匹、10～60 FPS。
- 停止約0.8秒後に接近、移動速度35物理px/秒超で逃避。
- アイコン矩形取得は約2秒周期。プレビューではアイコン回避を行わない。
- 省電力ON時、バッテリーでは最大15 FPS。停止中も操作・復帰の確認は行う。

## 今回のMVPに含まないもの

macOSのOS連携、魚以外のモデル、モデル選択UI、全画面の複数モニター対応、GPU compute、自動起動登録、インストーラー、署名は未実装。これらを現在の成果として説明しない。今後の実装順はユーザーの依頼に合わせて決める。

外部サービスへの送信やマウス履歴保存は現在のアプリに不要。要件変更がない限り追加しない。

## 実機で確認する受入項目

通常起動での壁紙配置、アイコンの前後関係、デスクトップ操作、実マウスの接近・逃避とOFF、アイコン移動後の追従、トレイ操作と設定保存・再起動、省電力の各切替、終了後の復元を確認する。自動テストやGPUの8秒間の起動成功だけで全項目を合格にしない。
