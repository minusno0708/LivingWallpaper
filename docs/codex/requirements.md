# 要件

最終整理: 2026-11-01。実装済みであることの証明ではありません。実装状況は [status.md](status.md)、検証結果は [validation.md](validation.md) で別に管理します。

## 目的・方針

自然や生物の群れの振る舞いをPCの壁紙上でシミュレーションする。アプリ名は `Living Wallpaper`、パッケージ名は `living-wallpaper`。魚だけに用途を限定する名称へ戻さない。

主対象はWindows 11。将来macOSも対象にできるよう、共通モデル・描画とOS固有処理を分離する。パフォーマンスと低負荷を技術選定・実装の判断基準にする。

## 機能要件とMVPの判断

| ID | 要件 | MVPの範囲・受入観点 |
|---|---|---|
| F1 | PCの背景として設定できる | Windows 11の有効な全モニターでアイコン背面に表示し、通常のデスクトップ操作を妨げない。終了後は通常の壁紙が見える |
| F2 | 設定画面は基本的にバックグラウンド、ポップアップ形式 | 常駐中はトレイから小さな設定ウィンドウを開く。連続変更しても閉じず、その場で反映・保存する。閉じる操作は常駐終了と区別する |
| F3 | 複数の群れモデルを選択できる拡張性 | 最初は魚のBoidsのみ実装。モデル追加の境界を用意し、複数モデルの実装・選択UIは後続作業 |
| F4 | デスクトップアイコンが障害物になる | アイコンとラベルの矩形を読み、魚が回避する。アイコンの移動後も取得周期に応じて追従する |
| F5 | マウスカーソルが群れに影響する | 停止すると接近、動くと逃避。ON/OFF可能。物理ピクセル座標を群泳座標に合わせる |
| F6 | FPS制限・省電力 | FPS上限と0 FPSによる手動停止。バッテリー駆動時の上限低下、全画面・ロック・スリープ時の描画抑制 |
| F7 | 設定の保持 | 操作後に保存し再起動時に反映。読み込んだ値を安全な範囲に制限する |

## 技術要件

- Rust + wgpuを共通基盤とする。現在のMVPではwinit、windows-sysを併用。
- CPUシミュレーションとGPUインスタンシングで描画する。GPU computeの利用は必須要件ではない。
- 不必要な常時描画やビジーループを避け、低速フレームでもシミュレーションの更新幅を制御する。
- Windows非公開API・Explorer内部構造への依存を明記し、失敗時の診断とプレビュー経路を残す。
- macOS未対応箇所を明示する。Windowsだけの成功をクロスプラットフォーム対応の証明としない。
- ソース、ビルド手順、検証結果を保存し、別PCで再現できるようにする。

## 現在のMVPで採用したパラメーター

以下は実装上の初期値・選択肢であり、ユーザーが固定した永続的な製品要件ではありません。変更時は動作・負荷・設定互換性を確認します。

- 初期値240匹、30 FPS。魚の数は10〜1000匹の10匹刻みスライダー、FPSは0〜120を15刻みにした9段階スライダー。
- 設定読込時も魚の数を10〜1000匹の10匹刻み、FPSを0〜120の15刻みへ正規化する。旧設定の端数は最も近い値へ寄せる。
- 停止10秒後から42〜200物理pxの範囲で接近、移動速度35物理px/秒超で逃避。
- アイコン矩形取得は約2秒周期。プレビューではアイコン回避を行わない。
- 省電力ON時、バッテリーでは最大15 FPS。停止中も操作・復帰の確認は行う。

macOSのOS連携、魚以外のモデル、GPU compute、自動起動登録、インストーラー、署名は未実装。これらを現在の成果として説明しない。今後の実装順はユーザーの依頼に合わせて決める。

外部サービスへの送信やマウス履歴保存は現在のアプリに不要。要件変更がない限り追加しない。

## 実機で確認する受入項目

通常起動での壁紙配置、アイコンの前後関係、デスクトップ操作、実マウスの接近・逃避とOFF、アイコン移動後の追従、トレイ操作と設定保存・再起動、省電力の各切替、終了後の復元を確認する。自動テストやGPUの8秒間の起動成功だけで全項目を合格にしない。

## 魚の表現（B案）

魚の見た目は、目・鱗・反射風の光沢を省いた抽象的なシルエットとする。葉のような先端のある胴体、二つに分かれる小さな尾、深海背景になじむディープブルーのフラットな色を使う。尾の振りは控えめにし、群れとしての動きを優先する。

遊泳アニメーションはBのしなりを基本とし、低速ではDの尾振りと滑走を混ぜる。速度の変化で急にモードを切り替えず、連続的に移行する。見た目の尾振りを速度に合わせるもので、Boidsの移動速度を周期的に加減速させる仕様ではない。


## 背景の表現（A案：静かな深海）

暗い青緑から深い紺へ変わる深度グラデーション、上部のごく淡い拡散光、ゆっくり漂う粒子で構成する。粒子の密度は初期の深海案より増やし、全体の明るさを抑えて魚の視認性を保つ。浅瀬向けの明るい光の帯・水中のノイズ表現は取り除く。魚やデスクトップアイコンを邪魔しない落ち着いた背景を優先する。魚のシルエットと速度依存の遊泳アニメーションは維持する。


粒子はマリンスノーを思わせる柔らかな大小の粒とし、遠景・中景・近景で大きさ・濃さ・沈降速度を変える。ゆっくり下へ沈みながら個体ごとに横揺れとわずかな回転を加え、星のような点滅や泡の上昇にはしない。


## 群れへの復帰と速度

近くに仲間が少ない個体は遠くの群れを探し、離れているほど強く加速して復帰する。通常の群泳に近づくにつれて復帰の力を弱める。最大速度は150px/sとし、加速度上限は通常600px/s²、孤立時は最大900px/s²とする。障害物・マウス・画面境界の回避と速度依存の尾振りは維持する。


初速は65px/s、最低速度は35px/s。群れ全体の固定巡航速度はなく、各個体の速度は周囲の仲間・障害物・マウス・境界と復帰力で変化する。復帰時の目標速度は距離に応じて120〜150px/s。


群れ全体の平均速度を少し上げるため、近傍に仲間がいる魚が70px/s未満の場合だけ、ごく弱い前進補助を加える。70px/sに固定する制御ではなく、回避・復帰・通常の群泳による速度変化と最大150px/sは維持する。


アイコン回避では、画面端に沿う縦列や重なる回避領域でも魚が押し戻され続けないようにする。起動時・匹数追加時の出現位置をアイコン内や画面端の狭い場所にしない。出現位置の安全確認と通常の回避距離は別にし、泳いでいる魚には必要以上に広い回避領域を設けない。侵入時は画面内の空いている側へ補正する。


静止10秒後のカーソルは半径24物理pxの円形衝突領域（魚の余裕を含む）として扱い、魚が中心を通り抜けず周囲を回り込む。実際のカーソル画像の形やサイズを取得する判定ではない。カーソル移動時とマウス影響OFF時にはこの衝突を使わず、既存の逃避・ON/OFFに従う。


設定画面の見出し「魚の群泳」は「モード」の選択欄に置き換える。現在の選択肢はFishのみとし、未実装モデルを選択可能にしない。選択モードを設定へ保存し、将来のモデル追加時に選択肢・モデル生成処理を拡張できるようにする。


0 FPSでは描画と群泳更新を停止し、設定画面と環境監視は継続する。スライダーの現在値だけを表示し、下部のFPS候補一覧は表示しない。


専用の一時停止チェック項目は設けず、FPS=0で手動停止を代用する。旧設定のpaused=trueは読込時にFPS=0へ移行し、以後pausedフィールドは保存しない。


画面を閉じるボタンは右上の×へ統一し、下部に「閉じる」ボタンを重複して設けない。下部の「アプリを終了」は常駐終了用として残す。Esc・トレイクリックによる非表示は維持する。


## 設定画面のDeep Glassデザイン

青いガラス風のA案を基に、濃い青のグラデーション、細い明るい縁、丸いスイッチ・スライダー、余白を使う。タイトルバーを含めて統一した見た目とし、閉じる操作は右上の×だけにする。表示名は「シーン」「カーソルに反応」「アイコンを避ける」「省エネ」「群れの大きさ」「なめらかさ」「終了」。数値は匹数・FPSの単位を保つ。機能や刻み、保存・常駐動作は維持し、宣伝文は加えない。


## シーン共通の時間倍率

全シーンへ共通に適用する「時間の速さ」を0〜2倍・0.25倍刻み、初期値1倍で設定・保存する。魚の移動・群泳・尾のアニメーション・背景の光とマリンスノーなど、シーン内の時間をまとめて拡縮する。倍率変更で経過時間を掛け直さず、動きが飛ばない連続した時計を使う。0倍、FPS=0、省エネによる停止では時計も止め、再開時に停止中の時間をまとめて進めない。

FPSは描画頻度、時間倍率はシーン内の進み方として独立させる。マウス静止10秒・移動速度判定・アイコン取得周期・環境確認・設定操作は実時間を維持する。将来のモデルにも共通の更新時間を渡し、魚だけの速度設定として実装しない。

設定画面のフォントはZen Kaku Gothic New Regularへ統一し、別PCでフォントのインストールを要求しない。


## マルチモニター拡張（2026-11-01）

初期状態で全モニターを有効にし、Windowsの物理ピクセル配置に沿った共通シーンとして扱う。負の座標を含む全画面の外接矩形へ壁紙ウィンドウを配置し、表示リージョンは有効画面の和集合に制限。無効画面・配置の隙間はモデルの障害物として渡し、アイコン回避OFFでも有効。隣接する有効画面間に内壁は作らず、魚の状態・背景時刻・匹数を全画面で共有する。非隣接画面へのワープは実装しない。

設定画面下部のモニタートグルは製品名（取得できない場合はGDIデバイス名）を表示し、切替は表示デバイス名で保存する。初期値のdisabled_displaysは空で、旧設定も全画面有効。新規接続画面は既定で有効。全画面OFFも許可し、常駐・設定操作は維持したまま描画・シミュレーションを停止する。画面構成は約2秒ごとに更新し、一覧は設定画面を開くと再取得する。設定画面の高さは一覧数に応じて拡張するため、多数の画面や小さい作業領域ではスクロール対応が今後必要。

Windows/GNU stableで27件成功・性能測定1件ignore。追加テストは隣接画面の内壁なし、負の原点、無効画面・斜め配置の空白、旧設定の全画面既定値・保存、モニタートグルの通知を対象とする。実機での複数画面・画面間移動・混在DPI・ホットプラグ・GPUをまたぐ構成は未検証。単一の大きなwgpu Surfaceを使うため、外接矩形の幅・高さはGPUの最大テクスチャ寸法以下が必要で、巨大な画面構成の分割描画は未実装。省電力の全画面判定は既存の代表モニター基準で共通シーン全体を停止する。macOS連携は未実装。
