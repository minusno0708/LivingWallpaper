## 共通時計とシミュレーション

SceneClockは実時間差分を0.1秒に制限してから倍率を掛け、1/60シーン秒以下へ分割する。累積時間を掛け直さず、倍率変更時の飛びを防ぐ。0倍・FPS=0・省電力停止からの復帰では停止中の時間を破棄する。魚・尾・背景は同じ時計、マウスの速度・静止判定とOS監視・UIは実時間を使う。

魚はCPUで更新し、GPUでインスタンス描画する。セル幅85pxの空間ハッシュで近傍を探索し、分離・整列・結合を計算する。仲間が3匹未満の個体は遠方セルの群れへ加速して復帰する。群れ全体の重心へ固定的に集めない。最低速度35、最大150px/シーン秒、初速65、巡航補助は70未満に弱く働く。加速度上限は通常600・孤立時900px/シーン秒²。

マウス移動速度35px/実秒超で220px内を逃避。静止10秒後は42〜200px内から接近し、半径24pxの円に対してスイープ衝突と回り込みを行う。

アイコンは8pxの余裕、28pxの局所回避と接線方向の誘導を使う。初期出現・追加個体には別の広い安全確認を行い、既存個体を毎フレーム再出現させない。侵入時は実矩形の辺・角から全障害物の外にある出口を選ぶ。連結障害物の外接矩形で空間を埋める近似はしない。画面端では位置だけをclampせず外向き速度を内側へ反転し、張り付きを防ぐ。

SchoolModel::fish()と描画契約には魚依存が残る。魚以外のモデルを追加する際に契約を見直す。

## Windowsとマルチモニター

WorkerW / Progman / 0x052CとExplorerのListView構造は非公開・不安定。通常のデスクトップ操作を妨げずアイコン背面へ配置する。Explorerウィンドウの非表示化・スタイル改変はしない。

座標は壁紙内の物理ピクセル。全画面の外接矩形を単一Surfaceとして描き、有効画面の和集合でウィンドウをクリップする。負の原点もScreenToClientで変換する。無効画面・配置の隙間は常時障害物として渡す。有効な隣接画面の境界に内壁はない。非隣接画面へのワープはない。

EnumDisplayMonitorsとQueryDisplayConfig / DisplayConfigGetDeviceInfoで位置と製品名を取得する。表示名と保存用のGDIデバイス名は分離する。全画面既定ON、disabled_displaysに除外先を保存。構成は約2秒ごと、設定一覧は開く際に再取得する。全画面OFFは描画・更新を止めるが常駐・設定は維持する。

単一SurfaceにはGPU寸法上限があり、巨大構成の分割描画は未実装。全画面アプリの検出は代表モニター基準で共有シーンを停止する。混在DPI・GPU・ホットプラグの実機保証とは区別する。

アイコン取得でExplorerへの通信がタイムアウトした場合、遅延書込先を失わないようリモートバッファを保持し、以後の取得を停止する。理由を理解せず即解放へ変更しない。

## 設定画面とリソース

トレイは専用スレッド。標準コントロールの値・フォーカス・Tab移動を使い、外観をGDIで独自描画する。背景は青いガラス風の不透明グラデーションで、Acrylic透過ではない。外周はDWMの角丸へ任せ、メイン設定ウィンドウにはリージョンを併用しない。

スライダーはドラッグ中にピクセル単位で追従し、値は指定刻みに丸める。解放時に一度だけ設定へ反映・保存する。静的ラベルの即時標準描画を避け、同値の文字列再設定を省く。トグルはオーナー描画で標準チェックの混入を防ぎ、短い間隔のクリックも一回ずつ処理する。180msのsmoothstepで移動・色を補間し、途中反転時は現在位置から再開する。16msのタイマーは動作中だけ有効。輪郭は局所的な4倍描画を縮小して平滑化し、文字は等倍を維持する。

Zen Kaku Gothic New RegularをEXEへ埋め込み、AddFontMemResourceExでプロセス内登録する。HFONT破棄後に登録を解除し、OSへインストールしない。魚のアイコンはリソースID 1、通知領域用の余白が小さい版はID 2。ビルド時はMSVCのrc.exeまたはGNUのwindresを使う。

## 設定と配布

設定はLOCALAPPDATA配下。旧FishSchoolWallpaperの設定があり新設定がない場合に引き継ぐ。旧paused=trueはFPS=0へ移行し、pausedを再保存しない。新項目がない旧設定は時間倍率1・全モニター有効として扱う。

個人情報・端末情報はGit管理外のdocs/localへ置く。公開用EXEはbuild.ps1の検査を通す。READMEのGIFはアプリの実行時依存ではなく、READMEをローカルでも表示するため配布へ同梱する。macOSのOS連携はスタブ。
